# Implementation Plan: Media Delivery Titles

**Branch**: `006-media-delivery-titles` | **Date**: 2026-10-18 | **Spec**: [spec.md](spec.md)

**Input**: `specs/006-media-delivery-titles/spec.md`

## Summary

Attach the request's source title to each delivered video or document as a literal
caption and safe filename. Cap captions and filename stems at 64 code points,
including a truncation ellipsis, while preserving whole grapheme clusters. Cap the
complete filename at 240 UTF-8 bytes, including ellipsis, dot, and extension. Add a
small pure title helper and call it at the validated delivery boundary. Preserve
request metadata, native bytes, local paths, cards, delivery methods, and retry semantics.

## Technical Context

**Language/Version**: CPython 3.13.

**Primary Dependencies**: Existing python-telegram-bot==22.8, yt-dlp[default]==2026.8.19,
instaloader==4.15.3; planned regex==2026.8.31 for Unicode grapheme segmentation.
Update pyproject.toml and uv.lock together during implementation.

**Storage**: Existing bounded in-memory request metadata and owned temporary files;
no new persistence or global title cache.

**Testing**: pytest and pytest-asyncio, controlled fixtures, fake Telegram transport,
injected clocks; manual Telegram verification separately recorded.

**Target Platform**: Existing Linux container and macOS development environment.

**Project Type**: Single-process Telegram bot with isolated source workers.

**Performance Goals**: No extra network calls or user actions; linear normalization
of already bounded metadata and bounded title output. Existing 60-second inspection
and 600-second download/send deadlines remain.

**Constraints**: 64 code points per caption/stem; 240 UTF-8 bytes per complete
filename including ellipsis/dot/extension; whole grapheme boundaries, literal
caption, unchanged bytes and stream-copy-only merges; 50,000,000-byte delivery cap,
128 MiB workspace, 900-second selection expiry and cleanup policy inherited from 001.

**Scale/Scope**: All currently supported single-item video, silent video, audio, and
picture journeys on YouTube, YouTube Music, LinkedIn, and Instagram; existing bounded
concurrency and request registry remain unchanged.
